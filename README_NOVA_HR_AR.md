# NOVA HR — Human Resource Management System

وصف المشروع 

NOVA HR هو مشروع نظام ويب لإدارة الموارد البشرية، يهدف إلى تنظيم وأتمتة العمليات الإدارية المتعلقة بالموظفين داخل المؤسسة من خلال واجهة موحدة وسهلة الاستخدام.

يساعد النظام على إدارة بيانات الموظفين والأقسام، وحسابات المستخدمين وصلاحياتهم، وطلبات الإجازات، والحضور والانصراف، والرواتب، وتقييم الأداء، والتقارير الإدارية.

الوحدات الرئيسية

Dashboard & Reports — لوحة التحكم والتقارير.

Employee Management — إدارة الموظفين.

Department Management — إدارة الأقسام.

Admin Management — إدارة الحسابات والصلاحيات.

Leave Management — إدارة الإجازات.

Authentication — تسجيل الدخول والمصادقة.

Payroll Management — إدارة الرواتب.

Attendance Management — إدارة الحضور والانصراف.

Training Management — إدارة التدريب (وحدة اختيارية).

Performance Evaluation — تقييم الأداء.

الحالة الحالية للمشروع

هذه النسخة تمثل الواجهة الأمامية التجريبية (Frontend Prototype)، وتعتمد بعض الوحدات فيها على بيانات محلية مخزنة في المتصفح باستخدام localStorage.

لم يكتمل بعد ربط جميع الوحدات بخادم Laravel وقاعدة البيانات المركزية، ولذلك لا تُعد بيانات النسخة الحالية بيانات إنتاجية أو نظامًا معتمدًا لإدارة سجلات الموظفين الفعلية.


## طريقة التشغيل على Windows
1. احتفظ بنسخة احتياطية من المشروع الحالي.
2. فك ضغط الحزمة وانسخ محتويات `hrms-frontend` إلى مجلد المشروع الحالي، أو افتح المجلد كما هو في VS Code.
3. افتح PowerShell داخل مجلد المشروع، وتأكد من وجود `package.json`.
4. نفّذ:

```powershell
npm install
npm run lint
npm run dev
```

5. بعد التأكد من عمل الواجهات نفّذ:

```powershell
npm run build
```

لا تنسخ مجلد `node_modules` من جهاز آخر؛ يجب إنشاؤه على النظام نفسه لتثبيت الحزم الثنائية المناسبة.

## تخزين البيانات التجريبي
تُحفظ البيانات في `localStorage` بمفاتيح تبدأ بـ `nova_hr_`. هذه بيانات متصفح محلية وليست قاعدة بيانات مركزية. مسح بيانات الموقع أو استخدام متصفح/جهاز آخر قد يؤدي إلى عدم ظهورها.
